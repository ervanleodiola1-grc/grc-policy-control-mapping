# GRC Project: Access Control Policy & Framework Mapping

## Executive Summary
This project outlines an enterprise Access Control Policy for a mid-sized healthcare technology startup handling sensitive patient data. It bridges high-level compliance frameworks (NIST CSF v2.0, ISO 27001:2022) with actionable operational controls.

## Project Deliverables
- [Company Profile](company-profile.md): Business context, regulatory requirements, and technical stack.
- [Access Control Policy](access-control-policy.md): Enforceable security policy covering authentication, RBAC, and offboarding.
- [Control Mapping Matrix](framework-mapping-matrix.csv): Cross-walk mapping policy requirements to NIST CSF v2.0 and ISO 27001:2022.
- [Gap Analysis & Remediation](gap-analysis-remediation.md): Identified implementation gaps and risk mitigation recommendations.

## Frameworks & Standards Covered
- **NIST CSF v2.0**: PR.AA-01, PR.AA-02, PR.AA-05 (Identity Management, Authentication, and Access Control)
- **ISO 27001:2022**: Annex A 5.15, 5.16, 5.18, 8.5
- **HIPAA Security Rule**: 45 CFR § 164.312(a)(1) (Access Control)

## Key Takeaways & Skills Demonstrated
- Policy drafting for technical and non-technical stakeholders
- Regulatory and framework control mapping
- Compliance gap identification and risk remediation planning
